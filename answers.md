# Відповіді на питання для самоконтролю

## 1. Чому важливо вказувати user.name та user.email?
Ці дані записуються в кожен коміт, тому видно, хто автор змін. GitHub за email зв'язує коміти з акаунтом користувача.

## 2. Яка різниця між git pull і git fetch?
git fetch лише завантажує нові дані з віддаленого репозиторію і не змінює робочі файли. git pull робить fetch, а потім зливає (merge) отримані зміни в поточну гілку.

## 3. Як скасувати останній коміт, не втрачаючи зміни у файлах?
Командою git reset --soft HEAD~1 (зміни залишаються в індексі) або git reset HEAD~1 (зміни залишаються у файлах, але не додані до індексу).
